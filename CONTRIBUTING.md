# Contribua com evidências

Abra uma issue para relatar uma aplicação, propor ajustes ou corrigir referências. Inclua contexto, problema, decisão, resultado observado e limitações. Remova dados privados.

Pull requests devem explicar qual problema resolvem e como foram revisados. Novas promessas de benefício precisam de evidência; novas práticas precisam de exemplos aplicáveis. Mantenha o método pequeno e reproduzível.

As contribuições são disponibilizadas sob a licença MIT deste repositório. Seja respeitoso e discuta ideias sem ataques pessoais.
